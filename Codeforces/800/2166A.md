# Same Difference 🧵✨

> *Some problems aren’t about changing everything.*
> *They’re about choosing what not to fight.*

---

## 🌍 The World of Letters

Once upon a runtime, there was a string `s` — a narrow street of houses, each painted a lowercase letter. 🏘️

The street had rules:

* You could **only** repaint a house to match its **right neighbor** ➡️
* No repainting backward. No shortcuts. No magic.
* One repaint = **one operation** ⏱️

The mayor had a simple request:

> **“Make every house the same color. Use the fewest repaints possible.”**

And yes — it was always possible.

---

## 🧠 The Insight (the quiet one)

Most people tried to argue with the whole street.

They counted colors. They simulated repaints. They fought entropy.

But one engineer noticed something subtle. Something… final.

They looked at the **last house**. 🏁

Why?

Because the last house is **untouchable**.

No one can repaint *it*.

So instead of asking:

> *“What should everything become?”*

They asked:

> **“What already cannot change?”**

---

## 🎯 The Strategy

Let the final house decide the future.

* Pick the **last character**
* Count how many houses already agree with it 🤝
* Every other house must eventually repaint to match it

No debates. No simulations.

Just alignment.

---

## 🧮 The Math (whispered, not shouted)

If:

* `n` = total houses
* `count` = houses already matching the last one

Then:

> **Minimum operations = `n - count`**

That’s it.

---

## ⚙️ The Code (the log of the journey)

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int main(){
    int t, n;
    string s;
    
    cin >> t;
    while(t--){
        cin >> n;
        cin >> s;
        
        char last = s[n-1];
        int count = 0;
        for(int i = 0; i < n; i++) if(s[i] == last) count++;
        
        cout << n-count << endl;
    }
}
```

No excess. No abstraction leaks.

Just counting what already agrees with the inevitable.

That’s not brute force.

That’s **acceptance as an algorithm**. 🧘‍♂️
