# 📈 Maximum Average — The Shortest Path to the Highest Peak

*A story about why the best answer is sometimes the smallest possible choice*

---

> When you are allowed to choose **any window**,
> the smartest move is often to choose **the smallest one**.

---

## 🌄 The Landscape

You are handed a tiny mountain range:

* An array `a` of length **n ≤ 10**
* Each height `a[i]` is between **1 and 10**

Your mission sounds grand:

> Find the **maximum average** of **any subarray**.

Any start. Any end. Any length.

At first glance, it smells like prefix sums, two pointers, maybe even binary search.

But the mountain is smaller than it looks.

---

## 🔍 The Definition That Changes Everything

The average of a subarray is:

[
\text{avg}(l,r) = \frac{a_l + a_{l+1} + \dots + a_r}{r - l + 1}
]

Notice the denominator.

Every extra element you include **dilutes** the result — unless it’s helping.

---

## 🧠 The Key Insight

> An average can **never exceed the maximum element inside it**.

Why?

Because the average is a weighted compromise.
It can rise *toward* the tallest peak — but it can never rise *above* it.

So the best possible average is achieved when:

* The subarray contains **exactly one element**, and
* That element is the **maximum value in the array**

🎯 One element. One peak. No dilution.

---

## 🧪 A Tiny Example

```text
Array: [3, 1, 4, 2]
```

Subarrays and averages:

* `[3]` → 3
* `[1]` → 1
* `[4]` → 4 ✅
* `[2]` → 2
* `[3,1]` → 2
* `[3,1,4,2]` → 2.5

No matter how wide the window gets…

🧱 nothing beats **4**.

---

## ⚙️ The Algorithm (Disguised as Common Sense)

1. Walk through the array
2. Keep track of the largest number seen
3. Print it

That’s it.

No loops inside loops.
No floating point.
No tricks.

---

## 🧾 The Code Ritual

```cpp
int maxi = INT_MIN;
for(int i = 0; i < n; i++){
    cin >> temp;
    maxi = max(maxi, temp);
}
cout << maxi << endl;
```

This isn’t laziness.

It’s mathematical respect.

---

## 🧠 Why the Answer Is Always an Integer

Because:

* Single-element subarrays are allowed
* Their average equals the element itself
* All elements are integers

The problem quietly **hands you the escape hatch**.

---

## 🏁 Final Verdict

| Choice                     | Average                |
| -------------------------- | ---------------------- |
| Any multi-element subarray | ≤ max element          |
| Single max element         | ⭐ **maximum possible** |
