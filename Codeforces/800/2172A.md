# 🎨 The ASCII Art Verdict

*A well-documented story about scores, sanity checks, and quiet logic.*

---

## 🧠 The Setup

Three AI-powered creative assistants step onto an unusual stage:

* **Gemini** — precise and polished
* **ChatGPT** — expressive and adaptive
* **Claude** — thoughtful and restrained

Their challenge is simple in description but subtle in execution: create ASCII art compelling enough to impress a panel of human judges.

Each judge submits a score.
Each score lives in a tight range.

```
80 ≤ score ≤ 100
```

But the organizers don’t just care about *how good* the art is.
They care about *agreement*.

---

## ⚖️ The Rule of Consensus

Before announcing a winner, the organizers apply a single consistency rule:

> **If the difference between the highest and lowest score is too large, the judging is considered unreliable.**

Formally:

* Let `max` be the highest score
* Let `min` be the lowest score

If:

```
max − min ≥ 10
```

Then the verdict is postponed.

```
check again
```

The judges must return to the table.

---

## 🎯 When Opinions Align

If the scores *are* close enough, the organizers don’t average.
They don’t vote.
They choose the **median**.

Why the median?

* It resists outliers
* It reflects the middle ground
* It represents consensus without compromise

Sorted scores:

```
[a, b, c]
```

The final announced score is:

```
b
```

Printed as:

```
final b
```

---

## 🧩 The Algorithm Behind the Curtain

Here is the exact logic that drives the decision, written in C++:

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main(){
    vector<int> scores(3);
    
    // Read the three judges' scores
    for(int i = 0; i < 3; i++) cin >> scores[i];

    // Sort scores to make comparison trivial
    sort(scores.begin(), scores.end());

    // Check consistency of judging
    if(scores[2] - scores[0] >= 10){
        cout << "check again" << endl;
    }
    else{
        // The middle score after sorting is the median
        cout << "final " << scores[1] << endl;
    }
}
```

---

## 🔍 Why This Works

This program succeeds because it:

* **Sorts early**, simplifying all later logic
* **Uses boundaries**, not assumptions
* **Avoids unnecessary branching**

Three inputs.
One sort.
One comparison.
One decision.

No bloat.
No ambiguity.

Good judging systems don’t chase perfection.

> It makes the right decision obvious—and the wrong one impossible.

This story ends the same way the contest does:

Either with confidence:

```
final X

check again
```
