# 🐔🐄 A Farm of Legs: Counting Configurations

Kaori wanted a quiet day.
Shizuku wanted animals.
The zoo was closed.

So they did what any good system does when a dependency fails: **they rerouted**.

Farmer John’s farm became the new execution environment.

---

## 🌾 The Observation

Shizuku squints at the field and starts counting carefully.

> "I see **n legs**."

Farmer John provides the hard constraints of the system:

* Only **chickens** and **cows** exist
* A **chicken** has **2 legs**
* A **cow** has **4 legs**
* Either animal may appear **zero or more times**

No tricks. No hidden states. Just legs.

---

## 🧠 The Question

Given a number `n`, how many **different farm configurations** are possible?

A configuration is defined by:

* The number of chickens
* The number of cows

Two configurations are different if **either number differs**.

This isn’t about *which* animal stands where.
It’s about **counts**, not permutations.

---

## 🔍 Reframing the Problem

Let’s translate the story into math.

If:

* `c` = number of chickens
* `k` = number of cows

Then the total number of legs must satisfy:

```
2c + 4k = n
```

This equation is the entire system.
Everything else is commentary.

---

## 🚦 First Gate: Is `n` Even?

Shizuku notices something immediately.

* Chickens contribute legs in **pairs**
* Cows contribute legs in **pairs of pairs**

Which means:

> **An odd number of legs is impossible**.

If `n` is odd, the answer is simple:

```
0 configurations
```

The system halts early.

---

## 🧮 Counting Valid Configurations

Assume `n` **is even**.

Now the question becomes:

> How many non-negative integer solutions exist for:
>
> `2c + 4k = n`

Divide everything by 2:

```
c + 2k = n / 2
```

Now we can iterate cleanly.

### 🐄 Start with Cows

Let `k` range from:

```
0 → n / 4
```

For every valid number of cows:

* The remaining legs are fixed
* The number of chickens is forced
* The result is always valid

Each value of `k` yields **exactly one configuration**.

---

## ✨ The Key Insight

The number of configurations is simply:

```
n / 4 + 1
```

Why the `+1`?

Because:

* Zero cows is allowed
* Maximum cows is `n / 4`
* We count **both ends**

This is inclusive range counting.

---

## 🧑‍💻 The Implementation

Farmer John smiles.
This logic fits in a single expression.

```cpp
#include <iostream>
using namespace std;

int main() {
    int t, legs;
    cin >> t;
    while (t--) {
        cin >> legs;
        int combo = legs % 2 ? 0 : (legs / 4 + 1);
        cout << combo << endl;
    }
}
```

Which matches:

```
8 / 4 + 1 = 3
```
