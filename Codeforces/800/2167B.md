# ❤️ Your Name — Rearranging Love

> Some problems aren’t about algorithms.
> They’re about proof.
>
> Not *I love you* — but *I can rebuild you from pieces.*

---

## 🧩 The Setup

Khba has **n cubes**. Each cube holds a **lowercase letter**.

Laid out in a row, they form a string:

```
s
```

His girlfriend’s name is also a string:

```
t
```

Same length. Same alphabet. Different order.

The question is simple, but loaded:

> ✨ *Can the letters of `s` be rearranged to become `t`?*

If yes → `YES`
If not → `NO`

No partial credit. Love is exact.

---

## 🔁 Multiple Universes (Test Cases)

This isn’t a single story.

We repeat it **q times**:

* Different lengths
* Different strings
* Same rules

Each test case is its own universe where love may or may not compile.

---

## 🧠 The Core Insight

Rearranging doesn’t change **what letters exist** — only **where they sit**.

So instead of asking:

> “Can I shuffle this?”

We ask:

> “Do both strings contain the **same letters, the same number of times**?”

That’s it.

No recursion. No brute force. No romance novel.

Just accounting.

---

## 🧮 Two Ways to Prove It

### ✨ Option 1: Sort and Compare (Conceptual)

If two strings, once sorted, look identical — they’re made of the same parts.

```cpp
sort(s.begin(), s.end());
sort(t.begin(), t.end());

if (s == t) YES else NO
```

Clean. Honest. Slightly heavier than needed.

---

### ⚡ Option 2: Count Letters (What the Code Uses)

We track **frequency**.

* Add counts from `s`
* Subtract counts from `t`
* If everything balances to zero → match 💫

This turns love into a checksum.

---

## 🛠️ The Implementation

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int q;
    cin >> q;

    while (q--) {
        int n;
        cin >> n;

        string s, t;
        cin >> s >> t;

        vector<int> count(26, 0);

        for (int i = 0; i < n; i++) {
            count[s[i] - 'a']++;
            count[t[i] - 'a']--;
        }

        bool possible = true;
        for (int i = 0; i < 26; i++) {
            if (count[i] != 0) {
                possible = false;
                break;
            }
        }

        cout << (possible ? "YES" : "NO") << '\n';
    }
}
```

---

## 🧪 Why This Works

* Alphabet size is fixed (26) 🧠
* String length ≤ 20 → no performance pressure
* Every increment has a matching decrement

If even **one letter** disagrees — love fails fast.

No backtracking. No maybes.

---

## 💌 The Metaphor

This isn’t about rearranging letters.

It’s about asking:

> *Do we have the same building blocks?*

Order can change.
Presentation can change.

But if the counts don’t match —

🚫 it was never the same name.

---

## ✅ Final Thought

Good algorithms don’t try every possibility.

They **remove impossibilities** until only truth remains.

And sometimes, that’s all love needs too. ❤️
